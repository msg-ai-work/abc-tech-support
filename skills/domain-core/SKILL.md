# 기술지원 도메인 Core Skill
## 적용 범위
- 고객사 발송클라이언트 설치/업그레이드
- 환경설정, 접속정보, 인증/권한, 네트워크 연계
- 파일/DB/API 기반 발송 연계
- 로그 수집 및 장애 진단
- OS/JDK/DB/네트워크 호환성 확인
- 고객 문의 재현, 가이드 작성, 원격/현장 지원
## 판단 순서
1. 설치/실행/발송 연계 문제인지 분리한다.
2. 버전/환경 호환성을 먼저 확인한다.
3. 설정 → 네트워크 → 인증 → 입력 → 발송 요청 → 응답/결과 순서로 점검한다.
4. 고객 환경과 메시징 시스템 문제를 분리한다.
5. 최초 오류와 연쇄 오류를 구분한다.
6. 임시조치와 근본조치를 분리한다.
## Guardrail
고객 비밀번호, 인증서 개인키, 운영 DB 접속정보를 저장하지 않으며 파괴적 명령을 AI가 자동 실행하지 않는다.
